세 단계로 Noir를 시작하세요. 마치고 나면 첫 코드베이스를 스캔해 API 엔드포인트를 찾아낸 상태가 됩니다.

| 단계 | 페이지 | 할 것 |
|------|--------|-------|
| 1 | **[Noir란?](overview/)** | Noir가 무엇이고 왜 필요한지 이해하기 |

| 3 | **[첫 번째 스캔](running/)** | 스캔 실행하고 결과 살펴보기 |

준비됐다면 **[Noir란?](overview/)** 페이지부터 시작하세요.

v0에서 업그레이드한다면 **[v0에서 v1로 마이그레이션](migrate_v0_to_v1/)** 문서를 보세요. 이름 변경 표, 동작 변화, 유일한 비호환 변경을 정리해 두었습니다.
